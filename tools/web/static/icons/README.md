# Icons served by the web control page

These are Lucide icons, byte-identical to the `icons/` files of the npm package `lucide-static` version 1.52.0 (https://lucide.dev). Each file keeps its own licence notice on its first line. Lucide is under the ISC licence, and the icons derived from Feather are also under MIT; both texts are in `LICENSE-lucide.txt`, which is the package's own `LICENSE`. Like the fonts, they are third-party files and not covered by the repository's MIT `LICENSE`.
